How to Host This Site for Free

Deploy live to stepien-stepien.com with zero ongoing fees

1 Create a Free GitHub Account & Repository

Go to github.com and sign up. Click the "+" icon in the top corner → "New Repository". Name it stepien-stepien and select **Public**.

2 Upload This Code File

In your new repository, click "Add file" → "Create new file". Name the file exactly index.html. Copy and paste all the code from this webpage directly into the editor and click "Commit changes".

3 Enable GitHub Pages

Go to Settings → Pages inside your repository. Under "Build and deployment", set **Source** to Deploy from a branch and select main branch. Click **Save**. Within 1–2 minutes, your website is live at a free URL!

4 Connect Custom Domain (stepien-stepien.com)

In GitHub Pages settings under Custom domain, enter stepien-stepien.com. In your domain provider DNS settings (where you bought the domain), add an **A Record** pointing to 185.199.108.153 and check **Enforce HTTPS** in GitHub.
